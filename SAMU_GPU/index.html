    一条命令复现

    Quick · 代表性矩阵

    python benchmark/run_benchmarks.py \
  --preset quick --output benchmark_results \
  --mamba-source /path/to/mamba \
  --rglru-source /path/to/recurrentgemma --resume

    Full · B/L/M/dtype/workload sweep，可恢复

    python benchmark/run_benchmarks.py \
  --preset full --output benchmark_results \
  --mamba-source /path/to/mamba \
  --rglru-source /path/to/recurrentgemma --resume
    Derived 页面中的 logical traffic 是公式计数，不等于 profiler-measured DRAM traffic。本环境没有 Nsight Compute，因此硬件计数器保持 N/A。
