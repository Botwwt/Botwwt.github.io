Architecture delta

优势不是少做 recurrence，
而是让它更容易融合。

两边使用相同模型宽度与相同 FP32 recurrent-state bytes。SAMU 保留 state-sized write，但把动态 transition 从逐通道 gate 收缩为两个 token 级坐标。

Official RG-LRU2× block-diagonal gates→channel-wise a, γ→Python sequence scan
SAMU Triton1× packed GEMM→shared c,d + static ν,θ→serial / C32 / fused decode
Recurrent state
512 B / batch64 complex FP32 vs 128 real FP32
Dynamic transition control
2 scalars / tokenSAMU c,d；RG-LRU gates 随 128 channels 展开
Prefill dispatch
shape-aware短 L serial；中段 C16；长 L C32
Decode
1 Triton launchprojection + control + transition + state update

Why it helps coherent control 让每个 program 只加载一次 c,d，再通过静态谱在寄存器中重建所有 mode transition；它没有消除 state-sized write，也不意味着优化后的 RG-LRU 必然慢。

    一条命令复现

    SAMU Triton vs official RG-LRU source

    cd benchmark
python run_samu_vs_rglru.py \
  --output ../benchmark_results_samu_rg \
  --rglru-source /path/to/recurrentgemma \
  --resume

    计时使用 synchronized CUDA events；首次编译、参数打包和 setup 不进入样本。短 runtime 的 decode 每个样本包含 100 次 inner iterations。

    Scope 当前新 kernel 是 inference-only；没有 backward 数字。网页也不把官方 PyTorch source 的 Python loop 开销包装成 RG-LRU 架构劣势。
