所有速度结论都来自 H800 实测。微内核先独立校准配置，再以前向/反向顺序复测；状态均为每个序列 2048 个 FP32 实标量。SAMU‑16 direct 是需要重新训练的架构候选，因此这里只报告系统速度，不把它写成已经成立的模型质量优势。

结构差异

真正可利用的差异，不是 scan 或 fusion，而是控制量维度和写入投影结构。

RG‑LRU‑16 为 2048 个实状态通道分别生成输入门与递推门。SAMU‑16 为 1024 个复数模态生成同样宽度的实写入，但动态 transition 只由两个共享标量控制。两边都使用分块扫描和融合解码；这些通用技术不作为 SAMU 的算法创新。

官方结构 RG‑LRU‑1616 组块对角投影
每个通道各有两组动态门→两次 sigmoid、两次 exp 与一次 sqrt 均按通道计算→RMSNorm + 融合递推；每步 2 次启动
SAMU‑16 GPU 候选16 组复数写入投影
每个 token 只保留 c,d 两个控制量→用共享 c,d 重建 1024 个静态谱模态的转移→RMSNorm/控制提取 + 融合递推；每步 2 次启动

由结构约束支持的优化 训练/预填充可对 ρj(c)=exp(−νjexp(c)) 使用带解析余项上界的四阶局部多项式；当前参数范围的保守上界为 8.03×10−10。它在长序列上有小幅收益，但单步解码反而约慢 4%，所以分派器只在长序列路径启用。

通用工程，不算算法发明

serial、chunk 与 fused decode

串行递推、仿射分块扫描和 kernel fusion 都是已有的 GPU 工程方法。我们的工作是为 SAMU 和官方 RG‑LRU 各自实现、校准并公平复测它们，而不是声称发明 scan 或 fusion。

SAMU 专属候选，需重训

16 组复数写入 + 直接共享控制

写入投影按 16 组布局，与 RG‑LRU 的论文默认分片对齐；两个控制量直接取自归一化后的两个通道，去掉额外控制器归约。这使 D=2048 的递推投影参数和 MAC 约减半，但改变了模型参数化，必须通过重新训练和质量实验后才能成为论文主张。

形状匹配

批量 8、状态宽度 1024，序列长度 2048、4096、8192、16384；与论文附录的关键扫描实验轴一致。

同等级实现

两边都测串行 Triton 和 chunk‑32 Triton；另外保留 BF16/FP32 materialized associative reference，用来说明实现策略的差异。

输入语义不同但透明

SAMU 每 token 消费 1024 个写入实标量和 2 个共享控制量；RG‑LRU 消费 1024 个输入值和已经投影好的 2048 个门值。

尚未测量

当前内核没有 backward；单卡也不能重现论文的模型并行 all‑reduce 与 ZeRO。网页把这些列为缺口，不用前向扫描结果代替。

SAMU 专属 GPU 适配

先把结构优势变成更少的投影，再看是否真的降低解码延迟

这一组固定 D=2048，计时范围是 RMSNorm 加一个递推更新。官方 RG‑LRU 使用 16 个门分块；SAMU 同时报告参数匹配的 grouped‑8、自然分片的 grouped‑16，以及需要重训的 direct‑control 候选。

RG‑LRU‑16：两组实门投影
N_{\mathrm{MAC}}^{\mathrm{RG16}}=2\times16\left(\frac{D}{16}\right)^2=\frac{D^2}{8}
SAMU‑16：一组复数写入投影
N_{\mathrm{MAC}}^{\mathrm{SAMU16}}=16\left(\frac{D}{16}\right)^2=\frac{D^2}{16}

    共同外壳固定为 D=2048、24 层、MLP 扩展 3、词表 32,000、BF16 参数与 FP32 递推缓存。两边直接引用同一套外壳张量，只替换官方 RG‑LRU‑16 与 SAMU‑16 direct 递推层；这是系统性能代理，不是训练好模型的质量对照。

    延迟

    固定批量 B=16，从空前缀和 4096-token 前缀开始，连续生成 128、256、512、1024、2048 和 4096 个 token。前缀处理时间不计入解码延迟。

    受限批量的完整轨迹吞吐

    先在 B=1、4、16、32、64、96、128、192、256 上运行 32-step 探针；取两种模型各自前两名批量的并集，再完整生成 512、1024、2048 和 4096 token。

    官方 RG‑LRU 结构

    从固定 commit 的 RecurrentGemma 创建 RG‑LRU，使用论文默认 16 个门分块。Triton 输出逐值对照官方 PyTorch：当前正确性审计已通过。

    结论边界

    两个模型都是固定大小递推状态，都没有随前缀增长的 KV cache。SAMU direct 需要重训；随机权重仅保证系统路径可执行，不说明困惑度或下游质量。
